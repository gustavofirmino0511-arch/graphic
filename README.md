# Unreal Medieval Demo

Este é o projeto de demonstração criado para o seu pedido. Contém:
- Código C++ para o personagem, terreno procedural e GameMode.
- Configurações de renderização e mapeamento de nível.
- Estrutura de diretórios (`Config`, `Content`, `Source`).
- Placeholder `.keep` para a pasta de models.

Abra `DemoWorld.uproject` no Unreal Engine 5 para iniciar o preview.
